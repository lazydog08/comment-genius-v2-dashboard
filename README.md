# 评论天才 V2 · 公开只读看板

查看业务概览，以及用户授权公开的完整保存记录：原评论、实际业务ID、草稿、回复、提交与确认、运行、故障及费用状态。

- [概览](https://lazydog08.github.io/comment-genius-v2-dashboard/)
- [完整记录](https://lazydog08.github.io/comment-genius-v2-dashboard/records.html)

网页只显示本机原生程序定期生成的只读快照，不执行采集、模型调用或发送。时间、完整性、未知费用和过期状态按真实来源显示；历史记录缺少正文或确认凭据时不会补造。

`snapshot.json`和`records.json`来自同一业务采样并在同一提交更新。网页不含登录凭据、Cookie、认证ticket、Key、原始数据库或私有配置；源码/浏览器资料不在此仓库。
